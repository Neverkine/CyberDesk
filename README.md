## 📌 О проекте

**CyberDesk** решает острую проблему финансового мошенничества и цифровой безграмотности. Платформа построена по принципу игрового микрообучения (Duolingo-модель): пользователи не читают скучные регламенты, а проходят интерактивные симуляции реальных атак через реалистичный интерфейс мессенджера.

### Ключевая специфика для Казахстана:
- **Kaspi.kz**: поддельные переводы, фейковые QR-коды для «отмены кредита», псевдо-сотрудники безопасности.
- **eGov.kz и контакт-центр 1414**: перехват кодов подтверждения и несанкционированный выпуск ЭЦП.
- **Мессенджеры (Telegram / WhatsApp)**: схемы «Голосование за родственника», ссылки на бесплатный Telegram Premium, вредоносные `.apk` под видом фото или документов.
- **Социальная инженерия**: срочные звонки лже-полиции и банковских операторов с требованием перевода на «безопасный счёт».

## 🚀 Ключевые возможности

### 1. 6 сквозных этапов подготовки (12 уроков)
Строгая последовательная разблокировка («череда») гарантирует методичный рост навыков:
- **Этап 01: Цифровая гигиена** — Пароли, 2FA и фишинговые ссылки.
- **Этап 02: Банковский финтех** — Kaspi QR-мошенничество и «ошибочные» переводы.
- **Этап 03: Госуслуги eGov.kz** — Налоговые уведомления и SMS-коды от 1414.
- **Этап 04: Мессенджеры и соцсети** — Угон Telegram-сессий и вредоносные ссылки.
- **Этап 05: Телефонные мошенники** — Звонки из «службы безопасности» и «родственник в ДТП».
- **Этап 06: Вредоносное ПО** — Банковские трояны, RAT и стилеры паролей.

### 2. Реалистичный симулятор диалогов
- Живая имитация переписки с мошенником с динамическими карточками подозрительных доменов.
- **Безопасная цена ошибки**: при опасном действии диалог останавливается, воспроизводится экран последствий, а наставник объясняет причину уязвимости и даёт возможность переиграть шаг.
- Пошаговое продвижение к следующему уроку прямо из экрана победы.

### 3. Наставники с уникальными стилями сопровождения
- **🛡️ Zero Trust (Строгий стиль)**: бескомпромиссная проверка фактов, жесткая дисциплина и нулевое доверие к неизвестным отправителям.
- **💚 Поддержка (Мягкий стиль)**: бережное объяснение, снижение стресса и паники при атаке.
- **💡 Аналитика (Обучающий стиль)**: глубокий разбор психологических манипуляций и технических векторов атак.
- **⚡ Конструктор своего ментора**: создание персонального наставника с уникальным именем, характером и стилем.

### 4. 🌐 Полная поддержка 3 языков (i18n)
Мгновенное переключение языка интерфейса без перезагрузки страницы:
- 🇰🇿 **Қазақша** (толық жергілікті бейімделу)
- 🇷🇺 **Русский**
- 🇬🇧 **English**

### 5. 🤖 Интеллектуальный API-ассистент поддержки (`/api/support`)
- Интеграция с **Google Gemini 1.5 Flash SDK** для генерации точных рекомендаций по кибербезопасности.
- **Zero-failure Fallback**: при отсутствии API-ключа или сетевых сбоях бот мгновенно отвечает через встроенную экспертную базу знаний платформы (обработка баг-репортов с выдачей тикетов, ответы по механике XP и стриков, правила защиты).

### 6. 📱 Адаптивность и портируемость
- Полноэкранный рабочий стол для ПК с расширенным дашбордом.
- Нативная адаптация для мобильных браузеров.
- Интерактивный режим «Мобильный вид» прямо в десктопной версии для демонстрации жюри.

### 7. 💾 Персистентность данных
Автоматическая синхронизация прогресса этапов, уровня, баланса кристаллов и опыта через `localStorage`: обновление страницы (F5) не сбрасывает пройденный материал.

## 💻 Быстрый старт

### Требования
- **Node.js**: 18.18+ или 20+
- **npm** или **pnpm**

### 1. Клонирование репозитория
```bash
git clone https://github.com/your-username/CyberDesk.git
cd CyberDesk
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Настройка переменных окружения (опционально)
Создайте файл `.env.local` в корне проекта:
```env
# Опционально. Если ключ не задан, платформа работает в оффлайн-режиме со встроенным движком.
GEMINI_API_KEY=your_gemini_api_key_here
```

### 4. Запуск в режиме разработки
```bash
npm run dev
```
Откройте [http://localhost:3000](http://localhost:3000) в браузере.

### 5. Сборка и запуск продакшн-версии
```bash
npm run build
npm run start
```
